# 📁 Laurent Manager

Un gestionnaire de fichiers puissant et élégant, créé par **Laurent Bajika**.

![Logo](https://img.shields.io/badge/Laurent-Manager-00ffcc?style=for-the-badge)

## 🎯 Description

Laurent Manager est une application de bureau qui permet de gérer facilement vos fichiers et dossiers :
- 📂 Navigation intuitive
- 🔍 Recherche rapide
- 📋 Copier / Couper / Coller
- ✏️ Renommer
- 🗑️ Supprimer avec confirmation
- 🛡️ Protection des dossiers système

## ✨ Fonctionnalités

| Fonctionnalité | Description |
|----------------|-------------|
| **Explorateur** | Naviguez dans vos dossiers |
| **Recherche** | Trouvez un fichier en tapant son nom |
| **Copier/Coller** | Dupliquez vos fichiers |
| **Couper** | Déplacez vos fichiers |
| **Renommer** | Changez le nom d'un fichier |
| **Supprimer** | Supprimez avec confirmation |
| **Sécurité** | Blocage des dossiers système |

## 🛠️ Technologies

- **Python 3**
- **Tkinter** (interface graphique)
- **OS** et **Shutil** (gestion des fichiers)
